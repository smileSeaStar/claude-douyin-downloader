# 抖音视频下载器 - 一键安装包

这是一个独立的可执行包，包含所有必要的文件和脚本。

## 文件说明

- `run.bat` - 一键启动程序（会自动检查并安装依赖）
- `check_env.bat` - 环境检测工具（手动检测环境）
- `gui_launcher.py` - 图形界面启动器
- `douyin_downloader.py` - 核心下载程序
- `requirements.txt` - Python 依赖列表

## 使用方法

### 方式一：一键启动（推荐）

直接双击 `run.bat`，程序会自动：
1. 检查 Python 是否安装
2. 自动安装所有依赖包
3. 启动图形界面

### 方式二：环境检测

双击 `check_env.bat` 可以：
- 检测所有依赖是否已安装
- 自动安装缺失的依赖包

## 系统要求

- Windows 10/11
- Python 3.8 或更高版本（首次运行会自动安装依赖）

## 功能

- 单个视频下载（无水印）
- Excel 批量下载
- 关键词检测（语音识别 + 字幕 OCR）
- 简繁转换支持
