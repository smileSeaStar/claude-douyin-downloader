# 抖音视频下载器打包发布流程

## 前置条件
- 当前工作目录：`D:\tools\test\claude-douyin-downloader`
- Git 已配置并连接到 GitHub
- Python 环境已安装

## 标准流程

### 1. Git 操作

```bash
# 查看当前状态
git status

# 添加修改的文件
git add douyin_downloader.py gui_launcher.py

# 提交更改（commit message 格式）
git commit -m "$(cat <<'EOF'
增加/修复：功能描述

主要更新：
1. 功能点1
2. 功能点2

Co-Authored-By: Claude Opus 4.6 <noreply@anthropic.com>
EOF
)"

# 创建并切换到稳定分支
git checkout -b stable/vX.Y.Z

# 推送分支到 GitHub
git push -u origin stable/vX.Y.Z

# 切回 master
git checkout master

# 推送 master
git push
```

### 2. 创建安装包

```bash
# 安装/确认 PyInstaller 已安装
pip install pyinstaller

# 打包 GUI 版本（单文件）
pyinstaller --onefile --windowed --name "抖音视频下载器" --icon=NONE gui_launcher.py

# 创建安装包目录
mkdir -p release_package
cp dist/抖音视频下载器.exe release_package/
cp douyin_downloader.py release_package/
cp gui_launcher.py release_package/
cp README.md release_package/ 2>/dev/null || echo "README不存在"

# 创建安装说明
cat > release_package/安装说明.txt << 'EOF'
抖音视频下载器 vX.Y.Z 安装说明
================================

一、一键运行版（推荐）
--------------------
1. 双击运行 "抖音视频下载器.exe"
2. 无需安装 Python 或其他依赖
3. 首次运行会自动下载浏览器驱动

二、源码运行版
-------------
1. 确保已安装 Python 3.8+
2. 安装依赖：
   pip install playwright openpyxl
   playwright install chromium

三、功能特性
-----------
✓ 单个视频下载
✓ Excel 批量下载
✓ 自定义下载路径
✓ 短链接支持
✓ 关键词检测（语音+字幕OCR）

四、版本信息
-----------
版本：vX.Y.Z
日期：YYYY-MM-DD
更新内容：
  - 功能点1
  - 功能点2
EOF

# 打包成 ZIP（精简版，只包含必要文件）
python -m zipfile -c 抖音视频下载器_vX.Y.Z_一键安装包.zip gui_launcher.py douyin_downloader.py run.bat check_env.bat requirements.txt README.md 使用说明.md

# 清理临时文件
rm -rf release_package
```

### 3. 创建发布说明

```bash
cat > release_notes.md << 'EOF'
# 抖音视频下载器 vX.Y.Z - 发布说明

## 🎉 新功能

### 1. 功能点1
- 详细描述

### 2. 功能点2
- 详细描述

## 📦 安装包

**文件名**：`抖音视频下载器_vX.Y.Z_一键安装包.zip`
**大小**：XX KB
**包含文件**：
- `gui_launcher.py` - GUI 启动器
- `douyin_downloader.py` - 核心下载器
- `run.bat` - 一键启动脚本
- `check_env.bat` - 环境检查脚本
- `requirements.txt` - Python 依赖
- `README.md` - 使用说明
- `使用说明.md` - 详细文档

## 🚀 使用方式

### 方式一：一键运行（推荐）
```bash
# 解压后双击 run.bat
run.bat
```

### 方式二：Python 运行
```bash
# 安装依赖
pip install -r requirements.txt
playwright install chromium

# 启动 GUI
python gui_launcher.py
```

## 📋 更新日志

### vX.Y.Z (YYYY-MM-DD)
- ✅ 功能点1
- ✅ 功能点2

### vX.Y.Z (YYYY-MM-DD)
- ✅ 基础功能

## 🔧 技术栈

- Python 3.8+
- Playwright 浏览器自动化
- OpenPyExcel 处理 Excel
- Tkinter GUI

## 📝 注意事项

1. 首次运行会自动下载浏览器驱动（约 100MB）
2. 确保网络连接正常，需要访问抖音服务器
3. 下载的文件名格式：`{标题}.mp4`
4. 批量下载时，Excel 文件中 A 列为视频链接

## 🤝 贡献

欢迎提交 Issue 和 Pull Request！

## 📄 许可证

MIT License
EOF

# 提交发布说明
git add release_notes.md
git commit -m "docs: 添加 vX.Y.Z 发布说明"
git push
```
